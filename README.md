# FLEX Assistant - Part 1+2 (project skeleton + Gemini brain + native app launcher)
Build: push to a GitHub repo (the included Actions workflow builds app-debug.apk), or run `gradle assembleDebug` with Android SDK + JDK 17.
Output: app/build/outputs/apk/debug/app-debug.apk
Open the app, tap Settings, paste your Gemini API key.
